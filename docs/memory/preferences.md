# Preferencias de trabajo

Cómo prefiere la persona responsable del proyecto que se trabaje y se comunique. Edita este archivo cuando cambie algo.

- Idioma: español rioplatense (Uruguay). No asumir el género de la persona al hablarle.
- Para tablas y análisis: responder en texto plano dentro del chat.
- No crear archivos HTML, tableros ni artefactos visuales salvo pedido explícito. (Los diagramas de arquitectura se pidieron de forma explícita y se entregan como imágenes dentro del documento.)
- No usar raya larga (em dash) al escribir informes y documentos en español.
- Quiere tener el control: skills, agentes, memoria y reglas deben ser archivos simples y editables dentro del repo.
- Quiere analizar las opciones por mérito técnico, sin condicionarlas por la situación actual (por ejemplo, sin descartar una opción solo porque hoy no hay servicio externo).
- Quiere que se le expliquen los problemas y lo que ofrece cada solución antes de decidir cuando hay compromisos reales.
- Primero se documenta y se decide. No se empieza a programar hasta que lo indique.
